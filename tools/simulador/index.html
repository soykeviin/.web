Cómo cargar tus datos reales

  1. En MT5 (VT Markets): Ver → Símbolos (Ctrl+U), pestaña Barras.
  2. Elige el CFD del Nasdaq (p. ej. NAS100), periodo M1, el rango de fechas y pulsa Solicitar.
  3. Pulsa Exportar barras y guarda el CSV.
  4. Aquí, pulsa Cargar CSV de MT5. Las horas del archivo son hora del servidor; ajusta el offset en "Horario" si hace falta.

Los primeros ~15 h de datos sirven de calentamiento de la EMA; el simulador no opera hasta tener al menos 60 velas M15.

Este simulador es una réplica en JavaScript de las reglas del EA, con ejecución tipo "1 minuto OHLC": cada vela M1 se recorre como apertura → mínimo/máximo → cierre, las limits de venta se llenan con el Bid y los stops de venta con el Ask (Bid + spread). Sirve para ver y revisar el comportamiento; no sustituye al Strategy Tester de MT5 con el EA real y ticks reales. Los datos de demostración son aleatorios y no representan el mercado: sus resultados no significan nada.
